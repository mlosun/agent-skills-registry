# 维护手册

> 面向维护者：6 个脚本的完整操作、端到端验证方法、故障排查。内容随项目演化持续更新（非一次性快照）。

## 一、脚本总览

| 脚本 | 职责 | 网络/LLM 依赖 |
| ------ | ------ | -------------- |
| `scripts/import.py` | 首次入库（GitHub → 镜像 + 元数据 + 扫描） | 需网络（git clone） |
| `scripts/security_scan.py` | 安全扫描引擎（rules.yaml 驱动） | 无 |
| `scripts/translate.py` | 中文描述翻译 | 需 DeepSeek key + 低谷时段 |
| `scripts/enrich.py` | 内容化（推荐理由 + 场景标签） | 需 DeepSeek key + 低谷时段 |
| `scripts/sync.py` | 上游同步（version patch+1 + 重扫） | 需网络（git clone） |
| `scripts/web.py` | 生成 GitHub Pages 站点 | 无 |

**依赖**：仅 PyYAML + git（系统自带）。运行：`python3 -m scripts.<脚本名>`（在仓库根目录）。

## 二、各脚本操作

### 2.1 import.py —— 入库

```bash
python3 -m scripts.import https://github.com/owner/repo    # URL 或 owner/repo
python3 -m scripts.import owner/repo --dry-run             # 演练不写盘
python3 -m scripts.import owner/repo --force               # 已存在则覆盖重入
python3 -m scripts.import owner/repo --include-drafts      # 连 in-progress/deprecated 一起
```

- 合集仓库自动枚举所有 SKILL.md；单 skill 仓库同逻辑
- 幂等：重复导入温和跳过（"已存在"提示）
- 每次入库自动跑安全扫描，写 risk 标签 + security-report.md

### 2.2 security_scan.py —— 安全扫描

```bash
# 扫单个 skill
python3 -m scripts.security_scan skills/<owner>/<repo>/<category>/<skill>
python3 -m scripts.security_scan <skill_dir> --no-report   # 不写报告

# 规则更新后批量重扫全部（同步 risk 到 meta/index）
python3 -m scripts.security_scan --rescan-all
```

规则库 `rules.yaml` 独立于引擎，增删规则不改代码。详见 [贡献指南.md](贡献指南.md#二安全规则)。

### 2.3 translate.py —— 中文翻译

```bash
python3 -m scripts.translate                      # 补全部缺的
python3 -m scripts.translate --skill <id>         # 只翻指定
python3 -m scripts.translate --dry-run            # 预览
```

- **时段护栏**：工作日北京时间 09-12/14-18 全价拒绝，`--force` 绕过；低谷 5 折
- 幂等：已翻译跳过；`description_en` 从 SKILL.md frontmatter 读，不重复维护
- key 来源：`DEEPSEEK_API_KEY` 环境变量 → `~/.pi/agent/auth.json`（deepseek.key）

### 2.4 enrich.py —— 内容化

```bash
python3 -m scripts.enrich                         # 全部生成推荐+标签
python3 -m scripts.enrich --dry-run               # 预览
```

- 一次 LLM 调用产出三样：`recommendation` + `tags` + （缺时补）`description_zh`
- JSON 结构化输出，解析容错；幂等跳过已有内容
- 与 translate 相同的时段护栏

### 2.5 sync.py —— 上游同步

```bash
python3 -m scripts.sync                           # 同步全部来源仓库
python3 -m scripts.sync --repo owner/repo         # 只同步指定
python3 -m scripts.sync --dry-run                 # 演练
```

- 按来源仓库为单位，对比 `upstream_sha`
- 无更新跳过；有更新：覆盖新代码 + **version patch+1** + 重扫 + **保留 description_zh**
- 上游新增 skill 自动入库（v1.0.0）；上游删除的本地保留 + 提示
- 每日 03:00 UTC 由 GitHub Action 自动运行

### 2.6 web.py —— 站点生成

```bash
python3 -m scripts.web                            # 生成 web/index.html + web/skills-data.json
python3 -m scripts.web --no-open                  # 不打开浏览器
```

- 读取 index.yaml + skill-meta.yaml，生成深色卡片网格单页应用
- 输出到 `web/`，push 后由 `deploy-site.yml` 自动部署 Pages
- **不要手动编辑 `web/`**；改 `scripts/web.py` 后重新生成

## 三、端到端验证方法

> 一次性验证结论（某时刻的 skill 数等）不在此记录——方法才是有价值的。以下命令可随时复跑，验证管道健康。

### 3.1 数据一致性自检

```bash
python3 - <<'PY'
import yaml
from pathlib import Path
idx = yaml.safe_load(open('index.yaml'))
ids = {r['id'] for r in idx['skills']}
disk = {str(m.parent.relative_to('skills')) for m in Path('skills').rglob('skill-meta.yaml')}
print('index 行数:', len(ids), '| 磁盘 meta 数:', len(disk), '| 一一对应:', ids == disk)
mismatch = []
for r in idx['skills']:
    meta = yaml.safe_load((Path('skills') / r['id'] / 'skill-meta.yaml').read_text())
    if meta.get('risk') != r.get('risk') or meta.get('version') != str(r.get('version')):
        mismatch.append(r['id'])
print('risk/version 双份不一致:', len(mismatch))
PY
# 预期：一一对应: True，不一致: 0
```

### 3.2 管道幂等验证

```bash
python3 -m scripts.import https://github.com/mattpocock/skills --dry-run   # 全"已存在"
python3 -m scripts.sync --dry-run                                          # 无更新
python3 -m scripts.translate                                               # 全部已有
python3 -m scripts.enrich                                                  # 全部已有
python3 -m scripts.security_scan --rescan-all                              # 全部 clean
```

### 3.3 测试套件

```bash
python3 -m pytest scripts/tests/ -v     # 期望全绿
```

覆盖：index 数据层、security_scan 引擎、translate 时段/API、sync 更新路径、enrich 内容化、web 站点生成。

## 四、故障排查

| 症状 | 可能原因 | 处理 |
| ------ | --------- | ------ |
| import/sync 克隆失败（SSL 错误） | 瞬时网络问题 | 重试（`git ls-remote` 先测连通） |
| translate/enrich 被拒绝 | 当前为高峰时段 | 低谷运行，或 `--force`（全价） |
| translate 译文为空 | 用了推理模型（如 v4-flash） | 用 `deepseek-chat`（非推理，默认值） |
| 报告大量 diff | `--rescan-all` 刷新了时间戳 | 结论未变时 `git checkout` 还原 |
| pyright 报"无法解析导入新模块" | 工具链索引滞后 | 运行时/测试正常即可，忽略 |
| 站点没更新 | push 未触发 deploy-site（paths 过滤） | 手动 `gh workflow run deploy-site.yml` |
