# 文档导航

本目录是 agent-skills-registry 的完整文档。按读者分为「对外」（想了解/使用/贡献的人）与「对内」（维护者）。

## 从哪开始读

```
想了解这个仓库是什么 → 架构说明.md
想给仓库加 skill   → 贡献指南.md
想自己维护/操作     → 维护手册.md
想了解历史决策      → 决策日志.md
想验收功能         → 验收清单.md
```

## 文档清单

| 文档 | 读者 | 内容 |
| ------ | ------ | ------ |
| [架构说明.md](架构说明.md) | 对外 | 仓库结构、双元数据、安全扫描模型、数据流、设计决策 1-3 |
| [贡献指南.md](贡献指南.md) | 对外 | 如何加 skill、安全规则怎么增删、审核标准、PR 规范 |
| [维护手册.md](维护手册.md) | 维护者 | 6 个脚本完整操作、端到端验证方法、故障排查 |
| [决策日志.md](决策日志.md) | 维持者+参考 | 决策 1-4 记录（分层/双元数据/YAML/同步翻译分工） |
| [验收清单.md](验收清单.md) | 维护者 | 阶段 1-6 验收步骤（改代码后自测） |

## 站点产物

`../web/` 目录存放 GitHub Pages 站点产物（`index.html` + `skills-data.json`），由 `scripts/web.py` 生成，经 `deploy-site.yml` 自动部署到 [https://mlosun.github.io/agent-skills-registry/](https://mlosun.github.io/agent-skills-registry/)。**不要手动编辑该目录**，改 `scripts/web.py` 后重新生成。
